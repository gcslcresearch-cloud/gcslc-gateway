# African Wealth Cloud Gateway — GCSLC Sovereign Command

**High-prestige Hugging Face Space:** True Map of Nigeria (36 state borders), Cumulative National Opportunity Cost Kill-Shot ($1.87 B/year), and 8R Humanoid Guardian.

## Run locally

```bash
pip install -r requirements.txt
python app.py
```

## Features

- **Map of Authority:** Plotly choropleth of the Federal Republic of Nigeria with all **36 state borders**. Coal-rich states in **Burnished Gold**, others in **Deep Navy**. Fully responsive (Samsung S24 Ultra and mobile).
- **5th Box (Kill-Shot):** Cumulative National Opportunity Cost front and center — **$1.87 Billion/year** loss with pulsing red Sovereign Warning.
- **8R Humanoid Guardian:** Navy & Gold humanoid with pulsing 8R determinants (Refine, Reset, Research, Restructure, Resuscitate, Revitalize, Re-engineer, Retain). Click any determinant for strategic importance to the Federation of AIs.

## True Map (36 state borders)

For the choropleth to render, add a GeoJSON file with Nigeria’s 36 state boundaries:

- Place **`data/ng_state.geojson`** in this repo (or in the Space’s files).
- Each feature must have a state name in `properties` (e.g. `adm1_name`, `shapeName`, or `name_1`). The 13 coal-reserve states will be colored Burnished Gold; the rest Deep Navy.

Without this file, the app shows a fallback message. No polygons or placeholders are used when GeoJSON is available.
